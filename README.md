# Homing Star 临时素材

`PendingArt/` 和 `PendingMusic/` 来自旧测试仓库的当前版本；`Art/` 保留本地原稿、精修文件、视频分析和录屏；`measurements/` 保留未提交的测量数据。

二进制原稿、图片、压缩包、音频和视频使用 Git LFS。克隆前安装 Git LFS，克隆后执行 `git lfs pull`。
正式采用资源需导入 `../homeing-star-game/assets/`，运行游戏不得直接加载本仓库。测试与导入工具位于 `../homeing-star-test/`，规约位于 `../homeing-star-doc/`。

GitHub：https://github.com/yuewen-huang/homeing-star-temp-assert
