# 岚：动作配色底稿

本目录只包含角色本体的非破坏性配色底稿，共 35 张。输出路径保留原动作目录层级；对应关系见 `action-base-manifest.csv`。

## 手修方式

在 Aseprite 打开底稿后，按原模板的分帧尺寸与网格设置导入。底稿已保留原图的画布尺寸、像素坐标和透明通道。请在此基础上补猫耳、猫脸、尾巴、发束和法袍细节。

## 范围

- 包含：攻击、闪避、蹲伏、治疗、受击、跳跃、梯子、悬崖、跑步、滑铲、墙跳等角色层。
- 未处理：`fx`、`merged`、烟雾、坠落和其他特效层。
- 不重复生成：已手修并接入游戏的 idle、起步、walk。

## 配色

底稿将模板长发替换为淡金色、衣物替换为深青色、皮革替换为棕色、肤色替换为淡金毛色。透明度和像素位置未改变。模板中未出现在既有配色表中的颜色会原样保留，详见 `unmapped-colors.csv`；它们大多是特定动作中的抗锯齿边缘色或附加阴影，留给手工判断。

生成脚本：`tools/aseprite/lan_batch_palette_bases.py`。手修后不要重新运行该脚本，否则会用模板重新生成底稿。
