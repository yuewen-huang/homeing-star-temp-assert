# 白金斩击四套变色

用 Python 脚本替换原金色，保留白色核心：1 红白、2 蓝白、3 橄榄绿白、4 黑白。

每套 18 个原生 Aseprite 动画，每个 6 帧，共 72 文件 / 432 帧。128×128 画布、像素位置、Alpha、独立 cel、图层名称/可见性/透明度、定位点、标签和帧时长均保留。没有新增图层。原白金文件未修改。

每套预览目录有全部动画 GIF、透明横向图集和 18 动作总览；黑白预览用浅色棋盘方便看黑色轮廓。根目录提供四配色静态/动画对比。GIF 调色板仅用于预览，原生 Aseprite 与 PNG 保留完整 RGBA。

本机 E:/Aseprite/Aseprite.exe 已批量打开全部 72 文件并导出；432 帧与脚本预期逐像素一致，所有 Alpha 与原动画一致。校验结果.json 保存源/输出 SHA256 与核验结果。

换色脚本位于 homeing-star-test/tools/recolor_platinum_slashes.py。
