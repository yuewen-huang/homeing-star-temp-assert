# 可复用的画风矫正提示词

将下文复制给图像模型，并附上矫正页。修改已有漫画时，还要附上待修改页；制作新页时，另行提供分镜内容。

---

请以附图《comic-style-calibration-v1.png》及同时提供的游戏原漫画为画风基准，统一这次漫画的绘制方式。矫正页只规定绘画语言，不提供新剧情。角色身份、服装和道具以各自已确认的原始设定为准。

如果提供了待修改页：保持原分镜、镜头、动作、对白原文、对白顺序与角色身份；只校正画风。不要因为参考页里有岚、风或城镇，就把待修改页替换成这些内容。

画风要求：

- 人物面部采用原漫画的柔和日式造型：清楚的大眼睛、简洁鼻口、自然脸颊与表情。保留原角色的头身比例，避免变成幼儿 Q 版或修长成人模特。
- 细而有粗细变化的深棕／炭灰线稿。头发保留成束结构与选择性细碎发丝，毛发以轮廓和少量内部笔触表达；不要把每一根毛都写实化。
- 以清楚的形体明暗为基础，结合柔和绘画笔触。面部简洁，衣物与环境细节丰富；保持同一页各格的完成度一致。
- 布料偏哑光，有自然褶皱；皮革有磨损与结构；旧金属只有小面积克制高光；石墙、木梁与地面有手绘纹理与明确边缘。
- 日景保持浅金阳光、蓝灰阴影与自然肤色；夜景保持深蓝环境光与局部琥珀灯光。根据新场景调整照明，不强制把全部画面染黄、压黑或变成夜景。
- 场景维持原漫画的石木建筑语言、空间纵深与细节密度。背景服务于人物阅读，不以虚化或大量光晕掩盖结构。
- 使用清晰深色格线与窄浅色格间留白；仅在目标页原有排版需要时保留其既定格线方案。

避免：写实人脸、照片材质、3D 渲染感、塑料反光、过度磨皮、整脸渐变喷枪、浓厚霓虹、夸张泛光、统一粗黑轮廓、平面矢量卡通、大片漫画网点、随意增加金色花纹或改造服装。

完成前请逐项对照参考图：人物脸型与头身比例、耳朵／口鼻／尾巴结构、发丝线条、服装轮廓、材质高光、日夜冷暖关系。同一角色在所有分格中保持一致。
